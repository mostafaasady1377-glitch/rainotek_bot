# 💻 ربات تلگرام جامع انبارداری و فروشگاهی راینوتک (Rhinotech)

یک سامانهٔ جامع، حرفه‌ای و قابل‌استقرار تلگرامی برای **فروشگاه کامپیوتر و لپ‌تاپ راینوتک (Rhinotech)** به همراه مدیریت موجودی چندشعبه‌ای، کاتالوگ درختی محصولات، ثبت درخواست خرید مشتریان، انبارگردانی دومرحله‌ای، جلوگیری از دوبار‌کلیک، و **اتصال مستقیم و زنده به Google Sheets**.

---

## 🌟 قابلیت‌های کلیدی

### ۱. بخش مشتریان (Customer Portal)
- 🖥 **کاتالوگ تعاملی و درختی:** مرور سلسله‌مراتبی بر اساس برند، سری، مدل و کانفیگ (پردازنده، رم، هارد، گرافیک، صفحه نمایش).
- 🏷 **تفکیک لپ‌تاپ‌های نو و استوک:** مشاهده وضعیت دستگاه (نو / استوک تمیز Grade A++) به همراه گارانتی رسمی.
- 🔎 **جستجوی هوشمند متنی:** جستجوی آنی بر اساس نام مدل، برند، رم یا پردازنده.
- 🛍 **ثبت درخواست خرید گام‌به‌گام:** فرم دریافت نام، شماره تماس، شعبه مورد نظر برای تحویل و توضیحات اختیاری.
- 📸 **نمایش مستقیم تصویر لپ‌تاپ بالای کارت مشخصات:** برای تمام مدل‌ها تصویر رسمی دستگاه به‌صورت خودکار در بالای مشخصات فنی، قیمت و موجودی شعب نمایش داده می‌شود.
- 🏢 **مشاهده شعب و آدرس‌ها:** نمایش مشخصات شعب راینوتک (صادقیه، میرداماد، فلاح، هروی، شهرک و...).
- 🛒 **پیگیری سفارشات:** امکان مشاهده وضعیت درخواست‌های قبلی کاربر.

### ۲. بخش پرسنل و شعب (Branch Managers & Staff)
- 🏢 **موجودی تفکیک‌شده به ازای هر شعبه:** ثبت و رصد موجودی اختصاصی هر لوکیشن.
- 📥 **ورود کالا (Stock In) و خروج کالا (Stock Out):** ثبت دقیق همراه با علت و مستندات.
- 🔄 **انتقال بین شعب (Branch Transfer):** جابجایی بین مبدا و مقصد با لاگ حسابرسی.
- 🛡 **سیستم جلوگیری از ثبت تکراری (Idempotency):** قفل ناهمگام و شناسهٔ یکتا به ازای هر عملیات برای مهار دابل‌کلیک یا تکرار بسته‌های وب‌هوک.

### ۳. بخش مدیریت کل (Admin Superpowers)
- 📋 **انبارگردانی دومرحله‌ای (Stock Audit):**
  - فاز ۱: شمارش فیزیکی اقلام توسط انباردار و تولید گزارش مغایرت کسری/مازاد.
  - فاز ۲: تایید رسمی توسط مدیر کل جهت اعمال خودکار مغایرت‌ها در موجودی.
- 📊 **اتصال زنده به Google Sheets:** همگام‌سازی موجودی و مشخصات از فایل شیت واقعی فروشگاه (`/sync_sheets`) و پایش وضعیت ارتباط (`/sheet_status`).
- 🔐 **امنیت و محرمانگی داده‌ها:** قیمت خرید و حاشیه سود فقط برای مدیر کل در دسترس است و در هیچ سناریویی به مشتریان یا کاربران عمومی نشان داده نمی‌شود.
- 👥 **مدیریت کاربران و نقش‌ها:** ارتقا یا عزل کاربران (`customer`، `branch_manager`، `admin`).
- 📈 **گزارش‌گیری پیشرفته:** دریافت موجودی کل و تاریخچه تراکنش‌ها در قالب فایل اکسل/CSV.

### نکته مهم درباره دسترسی نوشتن و تغییر شیت:
> ⚠️ **تفاوت دسترسی ایمیل شخصی با ربات تلگرام:**
> وقتی صاحب شیت دسترسی ویرایش را به ایمیل شخصی شما (Gmail) می‌دهد، فقط مرورگر شما می‌تواند تغییر ایجاد کند. ربات یک برنامهٔ سروری است و برای اعمال تغییرات خودکار در شیت یا اضافه کردن برگهٔ تراکنش‌ها، به یک **Google Cloud Service Account** نیاز دارد.

#### مراحل فعال‌سازی دسترسی خودکار نوشتن در شیت (اختیاری):
1. به [Google Cloud Console](https://console.cloud.google.com/) بروید.
2. یک پروژهٔ جدید بسازید و سرویس‌های **Google Sheets API** و **Google Drive API** را فعال کنید.
3. در منوی **IAM & Admin -> Service Accounts** یک سرویس اکانت بسازید.
4. در تب **Keys**، یک کلید از نوع **JSON** ایجاد و دانلود کنید.
5. این فایل را با نام `service_account.json` در ریشهٔ پروژه قرار دهید.
6. آدرس ایمیل سرویس اکانت (مشابه `bot-service@project-id.iam.gserviceaccount.com`) را در گوگل شیت با دسترسی **Editor** اد کنید (`Share -> Editor`).

## ⚙️ راهنمای راه‌اندازی و اجرا در ویندوز (Windows Setup)

### ۱. نصب پیش‌نیازها
- پایتون ۳.۱۱ یا بالاتر (از python.org با تیک Add to PATH)
- نرم‌افزار Git

### ۲. ساخت محیط مجازی و نصب وابستگی‌ها
در خط فرمان (PowerShell یا CMD) داخل پوشهٔ پروژه اجرا کنید:
```powershell
cd c:\Rainotek_AntiGravity

# ساخت محیط مجازی
python -m venv venv

# فعال‌سازی محیط مجازی
.\venv\Scripts\Activate.ps1

# به‌روزرسانی pip و نصب کتابخانه‌ها
pip install --upgrade pip
pip install -r requirements.txt
```

### ۳. ساخت توکن در تلگرام (BotFather)
1. وارد تلگرام شده و بات [@BotFather](https://t.me/BotFather) را باز کنید.
2. دستور `/newbot` را بفرستید.
3. نام بات (مثلاً `راینوتک | Rhinotech Store`) و نام کاربری (مثلاً `rhinotech_pc_bot`) را انتخاب کنید.
4. توکن ارائه‌شده (شبیه `7123456789:AAFx...`) را کپی کنید.
5. برای دریافت شناسه عددی تلگرام خود (Admin ID)، ربات [@userinfobot](https://t.me/userinfobot) را باز کنید و عدد Id خود را بردارید.

### ۴. تنظیم متغیرهای محیطی (`.env`)
یک نسخه از `.env.example` را به نام `.env` کپی کنید:
```powershell
Copy-Item .env.example .env
```
سپس فایل `.env` را باز کرده و مقادیر زیر را وارد کنید:
```env
BOT_TOKEN=7123456789:AAFx...توکن_شما...
BOT_USERNAME=rhinotech_pc_bot
ADMIN_TELEGRAM_IDS=123456789

# پایگاه داده محلی (بدون نیاز به نصب نرم‌افزار اضافه):
DATABASE_URL=sqlite+aiosqlite:///./rainotek.db

# شناسه گوگل شیت راینوتک:
GOOGLE_SHEET_ID=1jDWTufbdaTqG8gAn8xHp096j91wl9_pDXeKbrZ8KLYg

TZ=Asia/Tehran
```

### ۵. اجرای ربات
```powershell
python main.py
```
> در اولین اجرا، ربات به‌صورت خودکار دیتابیس محلی را مقداردهی کرده و در صورتی که دیتابیس خالی باشد، اطلاعات را از گوگل شیت راینوتک دریافت می‌کند.

## 🚀 راهنمای اجرای دائم و ۲۴ ساعته (24/7 Production)

### روش اول: سرویس ویندوز با ابزار NSSM (پیشنهادی برای ویندوز سرور)
1. برنامه کم‌حجم [NSSM](https://nssm.cc/download) را دانلود کنید.
2. پنجره خط فرمان را در حالت Administrator باز کرده و دستور زیر را بزنید:
   ```cmd
   nssm install RhinotechBot "c:\Rainotek_AntiGravity\venv\Scripts\python.exe" "c:\Rainotek_AntiGravity\main.py"
   nssm set RhinotechBot AppDirectory "c:\Rainotek_AntiGravity"
   nssm set RhinotechBot AppStdout "c:\Rainotek_AntiGravity\service_out.log"
   nssm set RhinotechBot AppStderr "c:\Rainotek_AntiGravity\service_err.log"
   nssm start RhinotechBot
   ```
   با این روش، در صورت ری‌استارت سیستم یا قطع برق، ربات بلافاصله با بالا آمدن ویندوز خودکار اجرا خواهد شد.

### روش دوم: سیستم استقرار لینوکس با Systemd (برای سرور مجازی اوبونتو/دبیان)
فایل `/etc/systemd/system/rhinotech.service` را بسازید:
```ini
[Unit]
Description=Rhinotech Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/Rainotek_AntiGravity
ExecStart=/opt/Rainotek_AntiGravity/venv/bin/python main.py
Restart=always
RestartSec=5
EnvironmentFile=/opt/Rainotek_AntiGravity/.env

[Install]
WantedBy=multi-user.target
```
فعال‌سازی سرویس:
```bash
sudo systemctl daemon-reload
sudo systemctl enable rhinotech
sudo systemctl start rhinotech
```

### روش سوم: داکر و PostgreSQL
برای پروژه‌های پرترافیک، می‌توانید از دیتابیس PostgreSQL استفاده کنید:
```env
DATABASE_URL=postgresql+asyncpg://postgres:secure_pass@localhost:5432/rhinotech_db
```
ساختار جداول به‌صورت خودکار در PostgreSQL ایجاد شده و ایندکس‌های بهینه اعمال می‌شوند.
